# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
include credentials, API keys, personal data or active exploit details in a
public issue.

Include the affected route or component, impact, reproduction conditions and a
minimal proof of concept. Reports are acknowledged as quickly as practical;
remediation timing depends on severity and deployment impact.
